### اجرای axe
در `npm run dev` مرورگر را باز کنید و در Console بزنید:

```js
const src = await (await fetch('/node_modules/axe-core/axe.min.js')).text(); (0, eval)(src)
const res = await axe.run(document, { runOnly: ['wcag2a', 'wcag2aa', 'best-practice'] })
res.violations.map((v) => v.id + ':' + v.nodes.length)
```

محدودیت: axe برای عناصر در حال انیمیشن یا پشت لایه‌ها گاهی «incomplete» می‌دهد؛ این موارد دستی بازبینی نشده‌اند.

## ۲. اجرای دستی چهار Flow در مرورگر (از دادهٔ بازنشانی‌شده)

- **A** بریف نمونه ← پردازش ← پیش‌نویس با شاهد و ابهام ← مسدودشدن تأیید ← حل ابهام‌ها ← Baseline v1.
- **B** نسخهٔ v1 ← Pin با مختصات ← بازخورد ← تصمیم نهایی ← v2 (اتصال تصمیم به نسخه) ← انتشار.
- **C** پورتال مشتری ← بازبینی ← تأیید دومرحله‌ای (و دو کلیک پشت‌سرهم) ← یک رسید.
- **D** درخواست مشتری ← پرسش و پاسخ ← طبقه‌بندی ← ارزیابی دستی ← پیشنهاد ← **رد** (بدون تغییر در Baseline و رسید)؛ و در جلسهٔ قبل، **پذیرش** ← Baseline v2.
- حالت‌ها: فضای خالی، خطای AI و Retry، فرم ناتمام، لینک ناشناس/باطل/منقضی، دادهٔ ذخیره‌شدهٔ خراب (بازیابی خودکار با دادهٔ نمونه)، خطای رندر (پیام و دکمهٔ بازنشانی).
- نقش‌ها: مدیر پروژه، مدیر استودیو و طراح روی صفحهٔ تغییرات.

## ۴. بازبینی بعد از بازطراحی بصری (فاز ۵: جهت E+D)

## ۲۱. بررسی Web Interface Guidelines (Vercel) و اصلاح‌ها

- `index.html`: `viewport-fit=cover`، `theme-color` (`#ebeae6`)، preload فونت arabic وزیرمتن.
- `index.css`: `scroll-padding-top: 7.5rem` (هدر چسبان)، `touch-action: manipulation`، رنگ tap-highlight، `text-wrap: balance` برای `h1`–`h3`، `tabular-nums` برای کل `body`، `overscroll-behavior: contain` روی `dialog`.
- فرم‌ها: `name` پیش‌فرض از `id`، `autoComplete="off"` پیش‌فرض برای فیلدهای غیرورود؛ ورود `username`/`password` با `autoComplete` درست. همهٔ placeholder ها با `…` و نمونه.
- ابطال لینک مشتری Dialog تأیید دارد (`DesignReview.tsx`).
- فیلترهای بازخورد (`status`, `vis`) و فیلتر و جست‌وجوی دفتر تصمیم (`filter`, `q`) در نشانی‌اند؛ در مرورگر با لینک و کلیک آزموده شد.
- شناسه‌ها و برچسب نسخه (`bdi`) `translate="no"` دارند (۳۸ مورد).
- رد شده چون برای فارسی/RTL معنا ندارد: Title Case، `&`، curly quotes، Hydration، dark mode.
- axe: ۰ خطا روی ۸ مسیر + ورود (۱۲۸۰px). ۸۰ آزمون سبز.
